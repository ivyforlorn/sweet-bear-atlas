SWEET DATA

让评分更新鲜一点

现在网站使用的是内置精选数据。填入 Google Maps API Key，就能在每座城市里获取 Google Places 的实时店铺、评分和评论。

  1. 1到 Google Cloud Console 启用 Places API (New)
  2. 2创建 API Key，建议限制只允许本网站来源
  3. 3把 Key 粘贴到这里，保存在你的浏览器本地

🔒 Key 只保存在本机浏览器（localStorage），请求直接发往 Google，不会经过任何第三方服务器。想深入了解可查看 Places API 文档。

没有 Key 也完全不影响逛地图。每家店的详情卡片里都有「在 Google Maps 查看」的链接，能看到最新的公开评分。
